# 视觉物料定位：顶部圆面与 30 mm 测距

## 判定流程

1. `modules.vision.drive.hough_lock.HoughRingLocator` 对 BGR 帧做灰度化、中值滤波，再用霍夫圆变换找物料顶部圆面。默认半径范围按实际帧尺寸计算，不要求固定三个物料。
2. 找到圆面就视为有物料，输出圆心和像素半径。没有圆面时不因 YOLO 框而报告物料。
3. `modules.vision.drive.material_face.measure_face` 给每个候选圆面两个只看灰度的指标：内部的灰度标准差（`interior_std`，物料顶面是一块单色圆面，所以很小）和圆周上真有径向边缘的方向占比（`edge_support`，背景上凑出来的圆接近 0）。两个都过关才算「像物料顶面」。
4. `modules.vision.drive.material_locate.MaterialLocator` 用固定的顶部**内侧浅蓝圆面直径 30 mm**计算镜头到圆面的大致距离。YOLO 只为圆面补充类别；YOLO 漏检时类别为未知，位置和距离仍保留。
5. `MaterialReport.best` 的取法：YOLO 认出类别时取置信度最高的；**一个框都没有时不再"取第一个圆"**（离心机位下一个夹爪圆弧就能让距离差几毫米到几十毫米），而是取最像顶面的那个；一个都不像就返回 `None`，`summary()` 会写明"距离不可用"。

`modules.vision.drive.material_presence` 与 `modules.vision.drive.material_distance` 是基于 YOLO 框的独立辅助模块，不参与这个主流程。

## 工作距离先验（近距机位必配）

霍夫的半径窗口默认按画幅猜（如 1280×720 下 26–259 px），这在**相机离物料很近**时不够用：物料顶面变得很大，而夹爪圆弧、背景平坦区也能凑出同样尺度的圆。实测 7 cm 机位（离焦画面）下，不设先验时每帧能凑出 7–8 个圆，距离读数在 69.5–383.7 mm 之间跳；设了先验并配合上面的顶面判据后，10/10 帧锁到同一个圆，读数 70.2 mm ± 0.3 mm。

先验就是把「相机装多高」写进 `modules/vision/config.json`：

```json
"targets": { "working_distance_mm": [60.0, 85.0] }
```

每一帧的半径窗口由针孔模型算出（近端给大半径）：`r = focal_px × 直径 / (2 × 深度)`。菜单 18 与 `python -m modules.vision.drive.material_locate` 都接受 `--depth 60,85` 覆盖它；`MaterialLocator(depth_range_mm=(60.0, 85.0))` 是程序里的入口。没配时行为与以前完全一致。

> **画面发虚时必须配这一项。** 近距离焦时圆边梯度被摊平，霍夫默认 Canny 高阈值 100 只会留下夹爪那种高对比弧线，锁到半径偏大的假圆（实测 248 px / 61 mm，真值 218 px / 70 mm）。`MaterialLocator` 现在会在严格参数没找到顶面时自动用 `HoughRingLocator.relaxed()`（阈值 50）再试一次；顶面判据负责在放松后的更多候选里挑出真的那一个。

## 距离与标定

`distance_mm = focal_px × 30 / (2 × radius_px)`。

对每个圆面，还按相机坐标系估算位置：`x_mm = (center_x_px - width/2) × z_mm / focal_px`，`y_mm = (center_y_px - height/2) × z_mm / focal_px`，`z_mm = distance_mm`。x 向画面右、y 向画面下、z 沿镜头向前；`range_mm = √(x_mm² + y_mm² + z_mm²)` 是圆面中心到相机的空间直线距离。这里近似认为主点在画面中心、水平与竖直像素焦距相等，尚未校正镜头畸变。

距离的绝对精度取决于两件事，两个都要自己量一次：

- **顶部圆面的真实直径**。代码按 30 mm 算；实测 7 cm 机位下顶面 433 px，正好对应 70 mm，与卷尺一致。直径若其实是 39 mm，所有距离都会小 30%。
- **像素焦距** `focal_px`。默认 1012 px 来自一张"约 145 mm"的照片，是粗标定；按 `focal_px = 已知距离 × 圆面像素直径 / 30` 在自己机位上重标一次即可（见 `modules/grasp/docs/抓取坐标链路.md` 实验 A′）。

半径每差 1 px，70 mm 处就差约 0.3 mm；所以判据选错圆的代价（十几到几十毫米）远大于标定误差，先验 + 顶面判据要一起用。

`models/top_pic_2.jpg` 是 1280×720 原图，内侧圆面直径约 209 px。拍摄时从镜头到圆面约 145 mm，且没有数码变焦，可反推该画幅的像素焦距约 `145 × 209 / 30 = 1012 px`。实测距离是约数，因此这是一次粗标定。

默认焦距只接受未裁切的 16:9 画幅，并按实际帧宽度从 1280 px 等比例换算。其他画幅须显式传入该画幅标定后的 `focal_px`；裁切或变焦不同也应重新标定。距离指镜头到物料顶部平面，不是机械臂末端距离。相机畸变和物料倾斜也会带来误差。

## 使用与验收

其他模块直接传入一帧原始 BGR 图像即可；检测器应在连续处理帧时复用：

```python
from vision import MaterialLocator

with MaterialLocator() as locator:
    report = locator.locate(frame)
    if report.present:
        for item in report.regions:
            print(item.name, item.confidence)
            print(item.center_x_px, item.center_y_px)
            print(item.x_mm, item.y_mm, item.z_mm, item.range_mm)
```

`report.present` 由霍夫圆面决定。`item.confidence` 是 YOLO 类别分数，不是校准过的真实概率；YOLO 漏检时 `item.name` 和 `item.confidence` 均为 `None`，圆心与三维估算仍保留。`item.distance_mm` 与 `item.z_mm` 同义。相机坐标不是机械臂坐标，机械臂使用前需要另行标定相机与机械臂的相对位姿。

下游只该拿 `report.best`，不要自己取 `report.regions[0]`：圆面是按 x 排序的，第一个不一定是物料。`report.best` 可能是 `None`（没锁到顶面），这时不要拿旧值继续算逆解。`report.faces` 是"像顶面"的子集，`report.radius_window_px` 是这一帧实际用的窗口，排查时先看这两个。

在项目根目录运行以下 PowerShell 命令；预期检出原图中一个圆面，圆心约 `(602,419)`、半径约 `105 px`，并保存标注图：

```powershell
python -m modules.vision.drive.material_locate --image models/top_pic_2.jpg --save output/top_pic_2_circle_result.jpg
```

仅检查霍夫定位时，预期同样检出一个圆面：

```powershell
python -m modules.vision.drive.hough_lock --image models/top_pic_2.jpg
```

真机运行 `python test.py` 并选菜单 18；程序向相机请求 1280×720，按 `p` 打印结论、按 `q` 退出。可通过 `--focal` 传入标定后的当前画幅像素焦距，`--depth` 覆盖 `config.json` 里的工作距离先验。画面上绿圈（加粗、带 `*`）就是 `report.best` 选中的那个，红圈是其余候选。

离线回归测试预期全部通过，不需要摄像头或安装依赖：

```powershell
python -m unittest modules.vision.test.unit.test_hough_lock modules.vision.test.unit.test_material_face modules.vision.test.unit.test_material_circle_pipeline modules.vision.test.unit.test_material_locate modules.vision.test.unit.test_material_camera_paths
```

当前验证样本只有一张完整顶视图和它的裁片，外加一台 7 cm 近距机位的实拍连帧。其他颜色、遮挡、不同距离及空场景的误检率仍需用相应实拍帧验收。近距 + 离焦这一组实测数据：不设先验时距离读数 69.5–383.7 mm（10 帧），设 60–85 mm 先验后 70.2 mm ± 0.3 mm，与亮色块的独立测量（432 px → 70.4 mm）一致；同一批帧 YOLO 一个框都没检出（同一模型在 `models/top_pic_2.jpg` 上 `obj-blue` 0.89），所以**类别仍不可用**——离焦画面的类别识别要么先把镜头对到工作距离，要么用这个距离下的实拍帧重训。
