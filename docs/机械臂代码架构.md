# 机械臂代码架构

机械臂控制分为四层，依赖方向只能从上到下：

```text
modules/arm/test/manual/arm.py               交互式真机测试
                 |
                 +--> robot_arm.py             三轴动作（脉冲制 + 带符号单位制）
                 |          |
                 |          +--> drive/kinematics.py              圆柱正逆解、最短转角、mm/度↔脉冲、可达性
                 |          |
                 |          +--> modules/motor/drive/motion.py     位置模式耗时估算（与底盘轮子共用）
                 |          |
                 |          +--> modules/motor/drive/emm42.py  Emm42 串口协议帧
                 |
                 +--> modules/arm/config.py      JSON 读取、类型和范围校验
                            |
                            +--> modules/arm/config.json  唯一可编辑的机械臂参数
```

## 改参数

日常参数只改 `modules/arm/config.json`，不改 Python：

- `motion.default_pulses`：命令行未传 `--pulses` 时使用的脉冲数。
- `motion.max_pulses`：CLI 和 `RobotArm` 都会拒绝超过该值的脉冲数。
- `motion.rpm`、`motion.acceleration`：所有位置模式帧共同使用的速度和加速度。
- `motion.pulses_per_revolution`：脉冲到电机轴角度的换算基准。
- `axes.*.motor_id`：三台驱动器地址；必须唯一。
- `axes.base.reduction_ratio`：5 号底座的减速比，用于输出轴角度换算（当前 5）。
- `axes.{lift,extension}.mm_per_motor_rev`：直线轴电机一圈走多少毫米，即 `L / g`
  （实验 B/C 标定，见 `docs/抓取坐标链路.md`）。为空时**拒绝下发毫米指令**。
- `limits.*`：三个轴的软行程范围；为空的那个轴不做检查，等于没有软件保护。
- `safe_pose`：转角度前后经过的安全位；三项必须同时给出或同时为 `null`。

`kinematics.py` 是**纯计算**：不打开串口、不读配置文件，所以能完全离线测试。
抓取流程（`modules/grasp`）用同一份实现，机械臂和视觉两侧不会各算一套。

配置载入时会拒绝缺失轴、重复地址、超出驱动器范围的速度或加速度、默认脉冲大于最大脉冲、
以及把 `reduction_ratio` / `mm_per_motor_rev` 填到错误的轴上。配置无效时，程序会在打开串口和
发送运动帧之前退出。

## 模块职责

- `modules.motor.drive.emm42.Emm42Driver`：只组装、发送和校验 Emm42 指令帧；不知道机械臂轴名称、行程或测试步骤。位置模式既接受角度（`move_relative`）也接受脉冲数（`move_relative_pulses`）。
- `modules/motor/drive/motion.py`：机械臂和底盘共用的运动参数约定与耗时估算（`estimate_move_seconds`）。Emm42 位置命令不等 ACK、也不回到位包，`wait=True` 只能按说明书的曲线加减速公式估算耗时。
- `robot_arm.RobotArm`：把“向上”“后缩”等机械语义映射为配置中的电机地址和 CW/CCW，统一执行相对位置模式、脉冲校验与角度报告；`pulses` 必填，`rpm` / `acceleration` / `wait` 可选，默认等到动作估完再返回。
- `robot_arm_config.load_arm_config()`：把 JSON 转为已校验的 `ArmConfig`，是配置文件和 Python 代码之间唯一的适配点。
- `modules.arm.test.manual.arm`：仅控制人工确认、执行顺序和清理；不保存运动参数。

离线测试通过注入 `ArmConfig` 和内存串口验证配置到帧字段的完整链路，不会打开真实串口。
