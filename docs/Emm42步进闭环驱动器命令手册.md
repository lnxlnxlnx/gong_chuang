## 〇、阅读约定

1. **字节序**：所有多字节数值都是**大端**（高位在前），例如速度 `05 DC` = 0x05DC = 1500。
2. **带符号量**：按手册的通用套路编码为「**符号字节 + 无符号数值**」，符号字节 `00` = 正数、`01` = 负数，
   例如实时转速 `01 05 DC` = −1500 RPM。
3. **校验字节**：默认固定 `0x6B`；本文所有帧都以 `6B` 结尾（XOR / CRC-8 / Modbus 见 1.3）。
4. **「返回帧总字节数」**：本文给出的是**整帧**长度，含地址字节、功能码、数据与校验字节。
5. 命令帧里的「地址」= 驱动器面板 `ID_Addr`，`00` = 广播。
6. 表中 `—` 表示手册**没有给出**该项内容；凡手册没写的都不补。

## 一、通讯参数与物理层（手册 6.1 / 6.2.1 / 4.2）

### 1.1 通讯参数

| 项目 | 值 | 出处 |
|---|---|---|
| 波特率 | 默认 **115200**；菜单 `UartBaud` 可选 9600、19200、25000、38400、57600、115200、256000、512000、921600 | 4.2 |
| CAN 速率 | 默认 **500000**（500KHz）；菜单 `CAN_Baud` 可选 10000、20000、50000、83333、100000、125000、250000、500000、800000、1000000 | 4.2 |
| 校验方式 | 默认 **0x6B**（固定帧尾）；可选 **XOR**、**CRC-8**、**Modbus** | 4.2 |
| 地址范围 | **1–255**，`0` 为广播地址 | 6.2.1 |
| 485 负载能力 | 理论上最多挂 **256 个从机** | 6.2.1 |
| CAN 负载能力 | 理论上最多连 **110 个节点** | 6.2.1 |
| 数据格式 | 8N1（手册只给了波特率；上位机设置见 6.2.2，未写数据位/停止位） | 6.2.2 |
| 供电 | 驱动器 V+ / Gnd 接 **7–32V**（上电自检提示推荐 12–32V，24V 动力足） | 3.1 / 3.2 |

### 1.2 地址与广播规则（6.2.1）

1. 地址默认 **1**，可设置范围 **1–255**，`0` 为广播地址。
2. 术语上手册混用「地址 / ID 地址 / 帧 ID」：串口/RS232/RS485 是帧首字节，CAN 是帧 ID（见 6.4）。
3. **以 0 地址发送命令时，所有闭环电机都会执行这条命令，但只有地址为 1 的电机会回复命令**，
   其他地址不回复。
4. 菜单 `ID_Addr` 的说明（4.2）写「选项 1、2、…、16，其他地址可用串口修改，范围 1–255」；
   而 6.2.1 写「地址 1-10 可以在菜单 ID_Addr 上选择修改，大于 10 的地址通过串口/CAN 发送命令修改」。
   两处不一致（第十六节第 7 条）。

### 1.3 校验方式（6.2.1 / 4.2）

| 校验方式 | 计算规则 |
|---|---|
| `0x6B`（默认） | 每条命令的**最后一个字节固定为 0x6B**，不做计算 |
| `XOR` | 最后一个字节 = 前面全部字节的异或。手册例：`01 06 45 42`，`0x42 = 0x01 ^ 0x06 ^ 0x45` |
| `CRC-8` | 最后一个字节 = 前面全部字节做 CRC-8 计算（手册未给出多项式与初值） |
| `Modbus` | 手册只写「请查看《Modbus-RTU 指令说明》文档」，本文不含 |

> 注意：6.2.1 正文说「可选 0x6B、XOR、CRC-8 **三种**」，而 4.2 的 `Checksum` 菜单是**四项**（含 Modbus）。
> 另外，`0x42 0x6C` 读回的「通讯校验方式」解析文字写「固定为 0x6B」，该字段能否读回真实校验方式，手册未说明。

### 1.4 四种接线方式（6.1）

| 方式 | 章节 | 手册给出的接线要点 |
|---|---|---|
| 串口 TTL | 6.1.1 | 单机/多机两种接法；**每个驱动器的插针左边都要横着插入两个跳线帽** |
| RS232 | 6.1.2 | 单机/多机；**每个驱动器都要插一个 ZDT_RS232 模块** |
| RS485 | 6.1.3 | 单机/多机；**每个驱动器都要插一个 ZDT_RS485 模块** |
| CAN | 6.1.4 | 单机/多机；**每个驱动器都要插一个 ZDT_CAN 模块** |

手册这几节的内容是接线示意图，正文只有上面这几句文字说明；图中具体线序本文不复述（图见原 PDF 第 30–33 页）。

端口复用的选择在菜单 `P_Serial`（菜单表见第十三节）：

- `RxTx_OFF`：关闭通讯端口，通讯控制无效；
- `ESI_ALO`：**R/A/H 复用为限位开关输入，T/B/L 复用为报警输出**；
- `UART_FUN`：R/A/H 与 T/B/L 复用为串口/RS232/RS485 通讯；
- `CAN1_MAP`：R/A/H 与 T/B/L 复用为 CAN 通讯。

### 1.5 上位机 / 串口助手设置（6.2.2）

勾选**16 进制发送**和**16 进制显示**，取消勾选**发送新行**，波特率默认 **115200**。

## 二、帧格式与应答机制（手册 6.2.1 / 4.2 / 8.1）

### 2.1 命令帧格式（6.2.1）

发送和接收都按同一格式：

```
地址        功能码       指令数据        校验字节
ID_Addr    Func_Code   [参数...]      CheckSum(默认 0x6B)
```

| 字段 | 长度 | 说明 |
|---|---|---|
| 地址 `ID_Addr` | 1B | 默认 1，范围 1–255，`00` = 广播 |
| 功能码 `Func_Code` | 1B | 部分命令第二个字节也算功能码的一部分（如 `F3 AB`、`FE 98`、`FF 66`、`93 88`、`4C AE`、`42 6C`、`48 D1`、`AE 4B` …） |
| 指令数据 | 0–N B | 随命令不同，多字节一律大端 |
| 校验字节 `CheckSum` | 1B | 默认固定 `0x6B` |

### 2.2 三种返回（6.3.1 起各条命令通用）

| 情况 | 返回帧 | 长度 | 手册示例 |
|---|---|---|---|
| 命令正确 | `地址 + 功能码 + 0x02 + 校验` | 4 字节 | `01 F3 02 6B` |
| 条件不满足 | `地址 + 功能码 + 0xE2 + 校验` | 4 字节 | `01 F3 E2 6B` |
| 错误命令 | `地址 + 0x00 + 0xEE + 校验` | 4 字节 | `01 00 EE 6B` |

注意第三种：**功能码位置是 `0x00`**，不是原命令的功能码（解析返回帧时要单独识别这一形态）。

### 2.3 `Response` 菜单的确切语义（4.2 / 8.1）

手册原文（4.2）：「设置串口/RS232/RS485/CAN 通讯控制时**控制动作命令列表**是否回复」；
（8.1）：「主机发送**控制动作命令列表**中的命令时，从机收到命令后，是否返回确认收到命令，以及是否返回到位命令」。

| 选项 | 确认收到命令 | 位置模式的到位命令 |
|---|---|---|
| `None` | **不返回** | **也不返回**（发送位置模式命令时也不返回到位命令） |
| `Receive`（默认） | **返回** | 不返回 |
| `Reached` | **不返回** | **只返回**到位命令（`地址 + FD + 9F + 6B`） |
| `Both` | 返回 | 返回 |
| `Other` | 返回（其他控制动作命令） | **位置模式下只返回到位命令** |

**作用范围（重点）**：手册把 `Response` 的作用范围**限定在「控制动作命令列表」（6.3.1）里的命令**上，
即：电机使能 `0xF3`、速度模式 `0xF6`、位置模式 `0xFD`、立即停止 `0xFE 0x98`、多机同步运动 `0xFF 0x66`。
4.2 的菜单说明与 8.1 的到位返回说明，两处都只提「控制动作命令列表」。

> **手册未说明**：`Response` 是否影响 6.3.2 / 6.3.3 / 6.3.4 / 6.3.5 里的读取、触发、修改类命令。
> 这些命令本身是「发一条、回一条数据」（例如 `01 31 6B` → `01 31 8D 9E 6B`），
> 手册没有把它们纳入 `Response` 的描述里。本仓库代码按「读取类命令不受 `Response` 影响」实现（见第十四节），
> 但这一点需要上机实测确认（尤其是 `Response=None` 的驱动器）。

### 2.4 多机通讯与同步控制（6.5）

多机：

- 每台电机 `ID_Addr` 必须唯一；
- `01 F6 01 05 DC 01 00 6B` → 只有 1 号电机执行（手册此例加速度为 `01`）；
- `02 F6 01 05 DC 01 00 6B` → 只有 2 号电机执行；
- `00 F6 01 05 DC 01 00 6B` → 1、2 号都执行（广播）。

同步三步法（手册 6.5 的原文例子）：

1. `01 FD 01 05 DC 08 00 00 7D 00 00 01 6B` → 1 号电机 **不立即运动**（多机同步标志 = 01），正确返回 `01 FD 02 6B`；
2. `02 FD 00 03 E8 0A 00 00 FA 00 01 01 6B` → 2 号电机 **不立即运动**，正确返回 `02 FD 02 6B`；
3. `00 FF 66 6B` → 两台电机**同时开始运动**。

> 即：先给各机发带「多机同步标志 = 01」的命令缓存住，最后播发同步触发帧。
> 手册示例里第 3 步用的是地址 `00`（广播），而 6.3.1 的命令示例用的是 `01 FF 66 6B`。

### 2.5 CAN 通讯控制（6.4）

1. 菜单 `P_Serial` 必须选为 `CAN1_MAP`；
2. CAN 通讯帧类型**固定为扩展帧**；
3. 命令格式与串口/RS232/RS485 **一样**，差别在「ID 地址」和「大于 8 字节的命令」；
4. CAN 帧 ID 在菜单 `ID_Addr` 中设置，默认 1，**发送时需左移 8 位**，低 8 位表示第几包数据；
   命令小于 8 字节时低 8 位保持 `00`；
5. 大于 8 字节的命令要**拆包**发送，**每一包都要带功能码**。

手册示例：

```
小于 8 字节（速度模式 01 F6 01 05 DC 01 00 6B）：一包发完，帧 ID 低 8 位 = 00

大于 8 字节（位置模式 01 FD 01 0F A0 00 00 01 FA 00 00 00 6B）：
  第 0 包：FD 01 0F A0 00 00 01 FA   帧 ID = 0100
  第 1 包：FD 00 00 00 6B             帧 ID = 0101
```

> 手册未说明：拆包后**地址字节**如何处理（示例里第 1 包不再出现地址 `01`，寻址由 CAN 帧 ID 承担），
> 也未给出 CAN 收到应答时的帧 ID 规则。

## 三、6.3.1 控制动作命令列表

> 本节 5 条命令都受 `Response` 菜单控制（见 2.3），手册也**逐条给出了**
> 「条件不满足 → `E2`」的返回与触发原因。

### 3.1 电机使能控制 `0xF3`

- **功能**：控制电机使能（锁轴）与不使能（松轴）。
- **命令格式**：`地址 + 0xF3 + 0xAB + 使能状态 + 多机同步标志 + 校验字节`（**6 字节**）
  - 使能状态：`01` = 使能，`00` = 不使能；多机同步标志：`01` = 启用，`00` = 不启用。
- **命令返回**：`地址 + 0xF3 + 命令状态 + 校验字节`（**4 字节**）
- **示例**：使能 `01 F3 AB 01 00 6B`，不使能 `01 F3 AB 00 00 6B`；正确返回 `01 F3 02 6B`。
- **数据解析**：第二个功能字节固定 `0xAB`；使能状态在它后面。
- **条件不满足**：`01 F3 E2 6B`（手册未列出本条的具体触发原因）。
- **错误命令**：`01 00 EE 6B`。

### 3.2 速度模式控制 `0xF6`

- **功能**：按设定方向与转速**持续转动**，直到收到停止或其他命令。
- **命令格式**：`地址 + 0xF6 + 方向 + 速度(2B 大端) + 加速度 + 多机同步标志 + 校验字节`（**8 字节**）
- **命令返回**：`地址 + 0xF6 + 命令状态 + 校验字节`（**4 字节**）
- **示例**：`01 F6 01 05 DC 0A 00 6B` → 正确返回 `01 F6 02 6B`。
- **数据解析**：`01` = 方向 CCW（`00` = CW）；`05 DC` = 速度 0x05DC = **1500 RPM**；
  `0A` = 加速度档位 10；`00` = 不启用多机同步（`01` = 启用）。
- **加速度曲线公式**（手册原文）：`t2 − t1 = (256 − acc) × 50(us)`，`Vt2 = Vt1 + 1(RPM)`；
  **加速度档位为 0 表示不使用曲线加减速**，直接按设定速度运行。
- **条件不满足**：`01 F6 E2 6B`，情况为**触发了堵转保护、电机没使能**。
- **错误命令**：`01 00 EE 6B`。

### 3.3 位置模式控制 `0xFD`

- **功能**：按设定方向、速度、加速度走到指定脉冲数位置（相对或绝对）。
- **命令格式**：`地址 + 0xFD + 方向 + 速度(2B) + 加速度 + 脉冲数(4B 大端) + 相对/绝对模式标志 + 多机同步标志 + 校验字节`（**13 字节**）
- **命令返回**：`地址 + 0xFD + 命令状态 + 校验字节`（**4 字节**）
- **示例**：`01 FD 01 05 DC 00 00 00 7D 00 00 00 6B` → 正确返回 `01 FD 02 6B`。
- **数据解析**：`01` = CCW（`00` = CW）；`05 DC` = 1500 RPM；`00` = 加速度档 0；
  `00 00 7D 00` = 脉冲数 0x00007D00 = **32000 个**；`00` = **相对位置模式**（`01` = 绝对位置模式）；
  `00` = 不同步（`01` = 启用同步）。
- **脉冲换算（手册 5.2 / 6.3.1）**：1.8° 电机 **16 细分下 3200 个脉冲转一圈**，
  32 细分则为 6400 个脉冲一圈；示例中 32000 个脉冲 = 10 圈。
- **条件不满足**：`01 FD E2 6B`，情况为**触发了堵转保护、电机没使能**。
- **错误命令**：`01 00 EE 6B`。

### 3.4 立即停止 `0xFE 0x98`

- **功能**：让电机立即停止转动（紧急刹车）。
- **命令格式**：`地址 + 0xFE + 0x98 + 多机同步标志 + 校验字节`（**5 字节**）
- **命令返回**：`地址 + 0xFE + 命令状态 + 校验字节`（**4 字节**）
- **示例**：`01 FE 98 00 6B` → 正确返回 `01 FE 02 6B`。
- **数据解析**：手册原文「可用于速度模式和位置模式都可以」。
- **条件不满足**：`01 FE E2 6B`，情况为**触发了堵转保护、电机没使能**。
- **错误命令**：`01 00 EE 6B`。

### 3.5 多机同步运动 `0xFF 0x66`

- **功能**：让多个电机同步开始运动（触发之前缓存的同步命令）。
- **命令格式**：`地址 + 0xFF + 0x66 + 校验字节`（**4 字节**）
- **命令返回**：`地址 + 0xFF + 命令状态 + 校验字节`（**4 字节**）
- **示例**：`01 FF 66 6B` → 正确返回 `01 FF 02 6B`；6.5 的多机示例用广播地址发 `00 FF 66 6B`。
- **数据解析**：需要各机先收到「多机同步标志 = 01」的命令（手册 6.5）。
- **条件不满足**：`01 FF E2 6B`，情况为**触发了堵转保护、电机没使能**。
- **错误命令**：`01 00 EE 6B`。

### 3.6 本节汇总

| 功能 | 功能码 | 命令帧长度 | 返回帧长度 | 手册示例帧 |
|---|---|---|---|---|
| 电机使能 | `F3 AB` | 6 | 4 | `01 F3 AB 01 00 6B` |
| 速度模式 | `F6` | 8 | 4 | `01 F6 01 05 DC 0A 00 6B` |
| 位置模式 | `FD` | 13 | 4 | `01 FD 01 05 DC 00 00 00 7D 00 00 00 6B` |
| 立即停止 | `FE 98` | 5 | 4 | `01 FE 98 00 6B` |
| 多机同步运动 | `FF 66` | 4 | 4 | `01 FF 66 6B` |

## 四、6.3.2 原点回零命令列表

### 4.1 设置单圈回零的零点位置 `0x93 0x88`

- **功能**：把电机当前位置设为单圈回零的零点位置（对应菜单 `O_Set → Set O`）。
- **命令格式**：`地址 + 0x93 + 0x88 + 是否存储标志 + 校验字节`（**5 字节**）
- **命令返回**：`地址 + 0x93 + 命令状态 + 校验字节`（**4 字节**）
- **示例**：`01 93 88 01 6B` → 正确返回 `01 93 02 6B`。
- **数据解析**：手册原文「可以让电机转到想要的位置，然后发送该命令设置单圈回零的零点位置」；
  是否存储标志 `01` = 存储（手册 7.1 的操作步骤用的就是 `01 93 88 01 6B`）。
- **条件不满足**：手册**只给了正确返回与错误命令返回**，未列 `E2` 条件。
- **错误命令**：`01 00 EE 6B`。

### 4.2 触发回零 `0x9A`

- **功能**：触发原点回零（四种模式之一）。
- **命令格式**：`地址 + 0x9A + 回零模式 + 多机同步标志 + 校验字节`（**5 字节**）
- **命令返回**：`地址 + 0x9A + 命令状态 + 校验字节`（**4 字节**）
- **示例**：`01 9A 00 00 6B` → 正确返回 `01 9A 02 6B`。
- **数据解析**：回零模式 `00` = 单圈就近回零、`01` = 单圈方向回零、`02` = 多圈无限位碰撞回零、
  `03` = 多圈有限位开关回零。
- **条件不满足**：`01 9A E2 6B`，情况为**触发了堵转保护、电机没使能、单圈回零的零点位置值无效**
  （「零点位置值无效」的判据手册未说明）。
- **错误命令**：`01 00 EE 6B`。

### 4.3 强制中断并退出回零操作 `0x9C 0x48`

- **功能**：正在回零的过程中，强制中断并退出回零。
- **命令格式**：`地址 + 0x9C + 0x48 + 校验字节`（**4 字节**）
- **命令返回**：`地址 + 0x9C + 命令状态 + 校验字节`（**4 字节**）
- **示例**：`01 9C 48 6B` → 正确返回 `01 9C 02 6B`（手册该行印作 `01 9C 0x48 6B`）。
- **数据解析**：无参数。
- **条件不满足**：`01 9C E2 6B`，情况为**当前没有触发回零操作**。
- **错误命令**：`01 00 EE 6B`。

### 4.4 读取原点回零参数 `0x22`

- **功能**：读回当前的回零参数。
- **命令格式**：`地址 + 0x22 + 校验字节`（**3 字节**）
- **命令返回**：`地址 + 0x22 + 原点回零参数(15B) + 校验字节`（**18 字节**）
- **示例**：`01 22 6B` →
  `01 22 00 00 00 1E 00 00 27 10 0F A0 03 20 00 3C 00 6B`
  （手册解析文字里这一段对应的是 `0F A0` 位置的字段写 `0x012C`，见第十六节第 2 条）。
- **数据解析**：15 个参数字节的排列见 4.7。
- **条件不满足**：手册只给了错误命令返回 `01 00 EE 6B`。
- **错误命令**：`01 00 EE 6B`。

### 4.5 修改原点回零参数 `0x4C 0xAE`

- **功能**：写入一组回零参数。
- **命令格式**：`地址 + 0x4C + 0xAE + 是否存储标志 + 原点回零参数(15B) + 校验字节`（**20 字节**）
- **命令返回**：`地址 + 0x4C + 命令状态 + 校验字节`（**4 字节**）
- **示例**：`01 4C AE 01 00 00 00 1E 00 00 27 10 01 2C 03 20 00 3C 00 6B` → 正确返回 `01 4C 02 6B`。
- **数据解析**（手册逐字段解释）：
  - `01` = 保存本次修改的配置参数；
  - `00` = 回零模式 Nearest（单圈就近）；
  - `00` = 回零方向 CW；
  - `00 1E` = 回零速度 30 RPM；
  - `00 00 27 10` = 回零超时时间 10000 ms（**4 字节**）；
  - `01 2C` = 无限位碰撞回零检测转速 300 RPM；
  - `03 20` = 无限位碰撞回零检测电流 800 mA；
  - `00 3C` = 无限位碰撞回零检测时间 60 ms；
  - `00` = 不使能上电自动触发回零功能。
- **条件不满足**：手册只给了错误命令返回 `01 00 EE 6B`。
- **错误命令**：`01 00 EE 6B`。

### 4.6 读取回零状态标志位 `0x3B`

- **功能**：读回零相关的状态标志位。
- **命令格式**：`地址 + 0x3B + 校验字节`（**3 字节**）
- **命令返回**：`地址 + 0x3B + 回零状态标志(1B) + 校验字节`（**4 字节**）
- **示例**：`01 3B 6B` → 手册给的返回形态是 `01 3B <回零状态标志字节> 6B`；
  解析举的例子是标志字节 = `0x03`。
- **数据解析**（位标志，手册逐位给出）：

| 位 | 掩码 | 含义 | 手册例子（标志 = 0x03） |
|---|---|---|---|
| bit0 | `& 0x01` | 编码器就绪状态标志位 | 0x01 = 就绪 |
| bit1 | `& 0x02` | 校准表就绪状态标志位 | 0x01 = 就绪 |
| bit2 | `& 0x04` | 正在回零标志位 | 0x00 = 没有在回零 |
| bit3 | `& 0x08` | 回零失败标志位 | 0x00 = 没有回零失败 |

  手册说明「回零失败」这一位由 `O_Tmo_Ms`（回零超时）置位：
  「回零超过这个时间就自动中断并退出回零，并置位回零失败标志位」。
- **条件不满足**：手册只给了错误命令返回 `01 00 EE 6B`。
- **错误命令**：`01 00 EE 6B`。

### 4.7 回零参数 15 字节排列（4.4 / 4.5 共用）

| 偏移 | 长度 | 字段 | 手册示例值 | 单位 / 说明 |
|---|---|---|---|---|
| 1 | 1B | 回零模式 | `0x00` = Nearest = 单圈就近回零 | 与 `0x9A` 的 00/01/02/03 对应 |
| 2 | 1B | 回零方向 | `0x00` = CW | CCW 的取值手册未说明 |
| 3 | 2B | 回零转速 | `0x001E` = 30 | RPM |
| 5 | **4B** | 回零超时时间 | `0x00002710` = 10000 | ms，**手册该字段是 4 字节** |
| 9 | 2B | 无限位碰撞回零检测转速 | `0x012C` = 300 | RPM |
| 11 | 2B | 无限位碰撞回零检测电流 | `0x0320` = 800 | mA |
| 13 | 2B | 无限位碰撞回零检测时间 | `0x003C` = 60 | ms |
| 15 | 1B | 是否使能上电自动触发回零 | `0x00` = 不使能 | 对应菜单 `O_POT_En` |
| 合计 | **15B** | — | — | 加地址、功能码、校验后，`0x22` 返回帧 18 字节，`0x4C AE` 写帧 20 字节 |

> 手册没有把 15 字节单独称作「回零参数块」，但 4.4 的返回示例（18 字节）与 4.5 的写示例（20 字节）
> 都严格按上表排列，字节数也能对上。

## 五、6.3.3 触发动作命令列表

四条命令的格式完全一致：**命令帧 4 字节、返回帧 4 字节**，手册示例的成功返回都是 `02`，
错误命令返回都是 `01 00 EE 6B`；其中只有 `06 45` 与 `0E 52` 手册给出了 `E2` 的触发原因。

### 5.1 触发编码器校准 `0x06 0x45`

- **功能**：触发编码器校准，对应屏幕上的 `Cal` 菜单。
- **命令格式**：`地址 + 0x06 + 0x45 + 校验字节`（**4 字节**）
- **命令返回**：`地址 + 0x06 + 状态码 + 校验字节`（**4 字节**）
- **示例**：`01 06 45 6B` → 正确返回 `01 06 02 6B`。
- **数据解析**：无参数；校准前应确保电机类型（`MotType`）正确、尽量空载（手册 3.4）。
- **条件不满足**：`01 06 E2 6B`，情况为**当前是开环模式、触发了堵转保护**。
- **错误命令**：`01 00 EE 6B`。

### 5.2 将当前的位置角度清零 `0x0A 0x6D`

- **功能**：将**当前位置角度、位置误差、脉冲数等全部清零**。
- **命令格式**：`地址 + 0x0A + 0x6D + 校验字节`（**4 字节**）
- **命令返回**：`地址 + 0x0A + 状态码 + 校验字节`（**4 字节**）
- **示例**：`01 0A 6D 6B` → 正确返回 `01 0A 02 6B`。
- **数据解析**：无参数；手册未给本条目的条件不满足返回。
- **错误命令**：`01 00 EE 6B`。

### 5.3 解除堵转保护 `0x0E 0x52`

- **功能**：电机发生堵转后，发送该命令解除堵转保护（不需要重新上电）。
- **命令格式**：`地址 + 0x0E + 0x52 + 校验字节`（**4 字节**）
- **命令返回**：`地址 + 0x0E + 状态码 + 校验字节`（**4 字节**）
- **示例**：`01 0E 52 6B` → 正确返回 `01 0E 02 6B`。
- **数据解析**：无参数；也可以把 `R/A/H` 引脚接 Gnd（0V）复位（手册 8.2 / `Clog_Pro` 菜单）。
- **条件不满足**：`01 0E E2 6B`，情况为**没有触发到堵转保护**。
- **错误命令**：`01 00 EE 6B`。

### 5.4 恢复出厂设置 `0x0F 0x5F`

- **功能**：恢复出厂设置。
- **命令格式**：`地址 + 0x0F + 0x5F + 校验字节`（**4 字节**）
- **命令返回**：`地址 + 0x0F + 状态码 + 校验字节`（**4 字节**）
- **示例**：`01 0F 5F 6B` → 正确返回 `01 0F 02 6B`；触发后**蓝灯亮起**，需要断电重新上电、重新空载校准编码器。
- **数据解析**：无参数；屏幕会提示 `Restore Done! Reboot!`（手册 9.1）。
- **条件不满足**：手册只给了错误命令返回 `01 00 EE 6B`。
- **错误命令**：`01 00 EE 6B`。

## 六、6.3.4 读取参数命令列表

### 6.1 读取固件版本和硬件版本 `0x1F`

- **功能**：读固件版本号与对应硬件版本号。
- **命令格式**：`地址 + 0x1F + 校验字节`（**3 字节**）
- **命令返回**：`地址 + 0x1F + 固件版本号(1B) + 硬件版本号(1B) + 校验字节`（**5 字节**）
- **示例**：`01 1F 6B` → 手册示例返回 `01 1F 7D 6F 6B`。
- **数据解析**：手册解析文字写「固件版本 = 0xF4 = Emm42_V5.0.0，对应的硬件版本 = 0x78 = 120 = ZDT_X42_V1.2 版本」，
  与示例帧的 `7D 6F` **对不上**（第十六节第 1 条）。两位均可当版本号直接读，具体对应关系需实测。
- **条件不满足**：手册只给了错误命令返回 `01 00 EE 6B`。

### 6.2 读取相电阻和相电感 `0x20`

- **功能**：读电机相电阻与相电感（校准编码器时测量并建模，3.4）。
- **命令格式**：`地址 + 0x20 + 校验字节`（**3 字节**）
- **命令返回**：`地址 + 0x20 + 相电阻(2B) + 相电感(2B) + 校验字节`（**7 字节**）
- **示例**：`01 20 6B` → `01 20 04 7A 0D 28 6B`
- **数据解析**：相电阻 = `0x047A` = **1146 mΩ**；相电感 = `0x0D28` = **3368 uH**（手册原文注明「注意单位」）。
- **条件不满足**：手册只给了错误命令返回 `01 00 EE 6B`。

### 6.3 读取位置环 PID 参数 `0x21`

- **功能**：读位置环 Kp / Ki / Kd。
- **命令格式**：`地址 + 0x21 + 校验字节`（**3 字节**）
- **命令返回**：`地址 + 0x21 + Kp(4B) + Ki(4B) + Kd(4B) + 校验字节`（**15 字节**）
- **示例**：`01 21 6B` → `01 21 00 00 F2 30 00 00 00 64 00 00 F2 30 6B`
- **数据解析**：Kp = `0x0000F230` = 62000；Ki = `0x00000064` = 100；Kd = `0x0000F230` = 62000；全部为大端无符号 4 字节。
- **条件不满足**：手册只给了错误命令返回 `01 00 EE 6B`。

### 6.4 读取总线电压 `0x24`

- **功能**：读总线（供电）电压。
- **命令格式**：`地址 + 0x24 + 校验字节`（**3 字节**）
- **命令返回**：`地址 + 0x24 + 总线电压(2B) + 校验字节`（**5 字节**）
- **示例**：`01 24 6B` → `01 24 5C 6A 6B`
- **数据解析**：总线电压 = `0x5C6A` = **23658 mV**（手册注：输入电压经过反接二极管后会有压降）。
- **条件不满足**：手册只给了错误命令返回 `01 00 EE 6B`。

### 6.5 读取相电流 `0x27`

- **功能**：读总线相电流。
- **命令格式**：`地址 + 0x27 + 校验字节`（**3 字节**）
- **命令返回**：`地址 + 0x27 + 总线相电流(2B) + 校验字节`（**5 字节**）
- **示例**：`01 27 6B` → `01 27 02 73 6B`
- **数据解析**：相电流 = `0x0273` = **627 mA**（手册单位写作 Ma）。
- **条件不满足**：手册只给了错误命令返回 `01 00 EE 6B`。

### 6.6 读取线性化校准后的编码器值 `0x31`

- **功能**：读经过线性化校准后的编码器值（**单圈绝对值**）。
- **命令格式**：`地址 + 0x31 + 校验字节`（**3 字节**）
- **命令返回**：`地址 + 0x31 + 编码器值(2B) + 校验字节`（**5 字节**）
- **示例**：`01 31 6B` → `01 31 8D 9E 6B`
- **数据解析**：编码器值 = `0x8D9E` = 36254。手册注：「经过线性化校准后，内部对编码器值进行了 **4 倍频**，
  **一圈的数值是 0–65535**」。
  **换算**：一圈 = 65536 个计数（手册另一处用量程 0–65535 描述，同一条命令的解析里两种写法并存）；
  **本命令只有单圈绝对值，区分不了圈数**，要带圈数的位置用 `0x36`。
- **条件不满足**：手册写「错误返回 `01 00 EE 6B`」。

### 6.7 读取输入脉冲数 `0x32`

- **功能**：读上位机输入（下发）的脉冲数（脉冲控制模式的下发计数）。
- **命令格式**：`地址 + 0x32 + 校验字节`（**3 字节**）
- **命令返回**：`地址 + 0x32 + 符号(1B) + 输入脉冲数(4B) + 校验字节`（**8 字节**）
- **示例**：`01 32 6B` → `01 32 01 00 00 0C 80 6B`
- **数据解析**：`01` = 负数（`00` = 正数）；`00 00 0C 80` = 0x0C80 = 3200，故输入脉冲数 = **−3200 个**。
  注意命令格式行手册只写「符号 + 输入脉冲数」，**没有写宽度**；由示例可确定为 **4 字节**。
- **条件不满足**：手册只给了错误命令返回 `01 00 EE 6B`。

### 6.8 读取电机目标位置 `0x33`

- **功能**：读电机**目标位置**。
- **命令格式**：`地址 + 0x33 + 校验字节`（**3 字节**）
- **命令返回**：`地址 + 0x33 + 符号(1B) + 电机目标位置(4B) + 校验字节`（**8 字节**）
- **示例**：`01 33 6B` → `01 33 01 00 01 00 00 6B`
- **数据解析**：`01` = 负数；`00 01 00 00` = 0x00010000 = 65536，`0–65535 表示一圈`，
  角度 = `(−65536 × 360) / 65536 = −360.0°`（手册原文的算式）。
- **条件不满足**：手册只给了错误命令返回 `01 00 EE 6B`。

### 6.9 读取电机实时设定的目标位置（开环模式的实时位置）`0x34`

- **功能**：读电机**实时设定的目标位置**（手册注：开环模式的实时位置）。
- **命令格式**：`地址 + 0x34 + 校验字节`（**3 字节**）
- **命令返回**：`地址 + 0x34 + 符号(1B) + 电机目标位置(4B) + 校验字节`（**8 字节**）
- **示例**：`01 34 6B` → `01 34 01 00 01 00 00 6B`
- **数据解析**：与 `0x33` 同结构；示例 = −0x00010000 → **−360.0°**；一圈对应 65536。
- **条件不满足**：手册只给了错误命令返回 `01 00 EE 6B`。

### 6.10 读取电机实时转速 `0x35`

- **功能**：读电机实时转速。
- **命令格式**：`地址 + 0x35 + 校验字节`（**3 字节**）
- **命令返回**：`地址 + 0x35 + 符号(1B) + 电机实时转速(2B) + 校验字节`（**6 字节**）
- **示例**：`01 35 6B` → `01 35 01 05 DC 6B`
- **数据解析**：`01` = 负数（`00` = 正数）；`05 DC` = 0x05DC，故实时转速 = **−1500 RPM**。
- **条件不满足**：手册只给了错误命令返回 `01 00 EE 6B`。

### 6.11 读取电机实时位置 `0x36`

- **功能**：读电机**实时位置**（编码器实测位置）。
- **命令格式**：`地址 + 0x36 + 校验字节`（**3 字节**）
- **命令返回**：`地址 + 0x36 + 符号(1B) + 电机实时位置(4B) + 校验字节`（**8 字节**）
  ——注意是 **8 字节**：符号字节 + 4 字节数值，别按「地址 + 功能码 + 4B + 校验 = 7 字节」算错。
- **示例**：`01 36 6B` → `01 36 01 00 01 00 00 6B`
- **数据解析**：`01` = 负数；实时位置 = −0x00010000 = (−65536 × 360) / 65536 = **−360.0°**；
  一圈对应 65536。「多圈计数是否掉电保持」**手册未说明**。
- **条件不满足**：手册只给了错误命令返回 `01 00 EE 6B`。

### 6.12 读取电机位置误差 `0x37`

- **功能**：读电机位置误差（目标位置与实时位置之差）。
- **命令格式**：`地址 + 0x37 + 校验字节`（**3 字节**）
- **命令返回**：`地址 + 0x37 + 符号(1B) + 电机位置误差(4B) + 校验字节`（**8 字节**）
- **示例**：`01 37 6B` → `01 37 01 00 00 00 08 6B`
- **数据解析**：`01` = 负数；误差值 `00 00 00 08` = 8；角度 = `(−8 × 360) / 65536 = −0.0439453125°`。
  （手册算式里写成 `−0x00000001`，与同一句里的 `8` 矛盾，见第十六节第 3 条。）
- **条件不满足**：手册只给了错误命令返回 `01 00 EE 6B`。

### 6.13 读取电机状态标志位 `0x3A`

- **功能**：读电机状态标志字节。
- **命令格式**：`地址 + 0x3A + 校验字节`（**3 字节**）
- **命令返回**：`地址 + 0x3A + 状态标志(1B) + 校验字节`（**4 字节**）
- **示例**：`01 3A 6B` → 手册示例 `01 3A 03 6B`。
- **数据解析**（位标志，手册逐位给出）：

| 位 | 掩码 | 含义 | 手册例子（标志 = 0x03） |
|---|---|---|---|
| bit0 | `& 0x01` | 电机使能状态标志位 | 0x01 = true |
| bit1 | `& 0x02` | 电机到位标志位 | 0x01 = true |
| bit2 | `& 0x04` | 电机堵转标志位 | 0x00 = false |
| bit3 | `& 0x08` | 电机堵转保护标志位 | 0x00 = false |

  到位判据（手册 8.1 / `0x42` 解析）：目标位置与实时位置之差小于**位置到达窗口**时置位到位标志。
  手册这两处都把判据写成不带绝对值的减法（第十六节第 4 条）。
- **条件不满足**：手册只给了错误命令返回 `01 00 EE 6B`。

## 七、6.3.5 修改参数命令列表

### 7.1 修改任意细分 `0x84 0x8A`

- **功能**：修改脉冲输入细分（对应菜单 `MStep`）。
- **命令格式**：`地址 + 0x84 + 0x8A + 是否存储标志 + 细分值 + 校验字节`（**6 字节**）
- **命令返回**：`地址 + 0x84 + 命令状态 + 校验字节`（**4 字节**）
- **示例**：`01 84 8A 01 07 6B` → 正确返回 `01 84 02 6B`
- **数据解析**：修改细分为 `0x07` = 7 细分并存储；**`00` 表示 256 细分**。
- **条件不满足**：手册只给了错误命令返回 `01 00 EE 6B`。

### 7.2 修改任意 ID 地址 `0xAE 0x4B`

- **功能**：修改本机地址（对应菜单 `ID_Addr`）。
- **命令格式**：`地址 + 0xAE + 0x4B + 是否存储标志 + ID 地址 + 校验字节`（**6 字节**）
- **命令返回**：`地址 + 0xAE + 命令状态 + 校验字节`（**4 字节**）
- **示例**：`01 AE 4B 01 10 6B` → 正确返回 `01 AE 02 6B`
- **数据解析**：把 ID 地址改为 `0x10` = 16 并存储到芯片上。改完地址后，后续命令要用新地址发。
- **条件不满足**：手册只给了错误命令返回 `01 00 EE 6B`。

### 7.3 切换开环/闭环模式 `0x46 0x69`

- **功能**：切换开环/闭环模式（对应菜单 `P_Pul`）。
- **命令格式**：`地址 + 0x46 + 0x69 + 是否存储标志 + 开环/闭环模式 + 校验字节`（**6 字节**）
- **命令返回**：`地址 + 0x46 + 命令状态 + 校验字节`（**4 字节**）
- **示例**：`01 46 69 01 01 6B` = 开环模式；`01 46 69 01 02 6B` = 闭环模式 → 正确返回 `01 46 02 6B`
- **数据解析**：模式字节 `01` = 开环，`02` = 闭环。
- **条件不满足**：手册只给了错误命令返回 `01 00 EE 6B`。

### 7.4 修改开环模式的工作电流 `0x44 0x33`

- **功能**：修改开环模式的工作电流（对应菜单 `Ma`）。
- **命令格式**：`地址 + 0x44 + 0x33 + 是否存储标志 + 开环模式电流(2B) + 校验字节`（**7 字节**）
- **命令返回**：`地址 + 0x44 + 命令状态 + 校验字节`（**4 字节**）
- **示例**：`01 44 33 00 03 E8 6B` → 正确返回 `01 44 02 6B`
- **数据解析**：电流 = `0x03E8` = **1000 mA**；本例是否存储标志为 `00`，即**不存储（断电丢失）**。
- **条件不满足**：手册只给了错误命令返回 `01 00 EE 6B`。

### 7.5 修改驱动配置参数 `0x48 0xD1`

- **功能**：一次写入整组驱动配置参数（21 个，与 `0x42 0x6C` 同一套字段，但不含帧长/个数两个头字节）。
- **命令格式**：`地址 + 0x48 + 0xD1 + 是否存储标志 + 驱动配置参数(28B) + 校验字节`（**33 字节**）
- **命令返回**：`地址 + 0x48 + 命令状态 + 校验字节`（**4 字节**）
- **示例**：`01 48 D1 01 19 02 02 02 00 10 01 00 03 E8 0B B8 0F A0 05 07 01 00 01 01 00 28 09 60 0F A0 00 01 6B`
  → 正确返回 `01 48 02 6B`
- **数据解析**：字节顺序与 `0x42 6C` 的参数区完全一致（见第十一节）；手册逐字段说明：
  `0x01` 保存本次修改（红字注明：**ID 地址那一位现取消，使得可用广播地址批量修改驱动参数**）。
- **条件不满足**：手册只给了错误命令返回 `01 00 EE 6B`。

### 7.6 修改位置环 PID 参数 `0x4A 0xC3`

- **功能**：修改位置环 Kp / Ki / Kd（对应 `0x21` 的可写版本）。
- **命令格式**：`地址 + 0x4A + 0xC3 + 是否存储标志 + Kp(4B) + Ki(4B) + Kd(4B) + 校验字节`（**17 字节**）
- **命令返回**：`地址 + 0x4A + 命令状态 + 校验字节`（**4 字节**）
- **示例**：`01 4A C3 00 00 00 F2 30 00 00 00 64 00 00 F2 30 6B` → 正确返回 `01 4A 02 6B`
- **数据解析**：`00` = 不保存本次修改；`0x0000F230` = Kp 62000；`0x00000064` = Ki 100；`0x0000F230` = Kd 62000。
- **条件不满足**：手册只给了错误命令返回 `01 00 EE 6B`。

### 7.7 存储一组速度模式参数，上电自动运行 `0xF7 0x1C`

- **功能**：存储「方向 + 速度 + 加速度」，每次上电自动按这组参数运行，并可用 En 引脚控制启停。
- **命令格式**：`地址 + 0xF7 + 0x1C + 存储/清除标志 + 方向 + 速度(2B) + 加速度 + 是否使能 En 引脚控制启停标志 + 校验字节`（**10 字节**）
- **命令返回**：`地址 + 0xF7 + 命令状态 + 校验字节`（**4 字节**）
- **示例**：`01 F7 1C 01 01 05 DC 0A 01 6B` → 正确返回 `01 F7 02 6B`
- **数据解析**：`01` = 方向 CCW（`00` = CW）；`05 DC` = 1500 RPM；`0A` = 加速度档 10；
  `01` = 启用 En 引脚控制启停（`00` = 不启用）。手册说明：发送该命令后每次上电，
  电机自动以加速度 10 加速到 **−1500 RPM** 运行，可用 En 引脚启停，En 的有效电平由菜单 `En` 决定（选 `H` 为高电平启动）。
- **条件不满足**：手册只给了错误命令返回 `01 00 EE 6B`。

### 7.8 修改通讯控制输入速度是否缩小 10 倍 `0x4F 0x71`

- **功能**：对应菜单 `S_Vel_IS`，使能后通讯下发的速度值缩小 10 倍（精确到 0.1 RPM）。
- **命令格式**：`地址 + 0x4F + 0x71 + 是否存储标志 + 缩小 10 倍标志 + 校验字节`（**6 字节**）
- **命令返回**：`地址 + 0x4F + 命令状态 + 校验字节`（**4 字节**）
- **示例**：`01 4F 71 01 01 6B` → 正确返回 `01 4F 02 6B`
- **数据解析**：`01` = 使能（`00` = 不使能）；使能后发 1 RPM 实际跑 0.1 RPM。
  手册注明：**速度模式控制指令、位置模式控制指令、存储速度模式参数指令都有效**。
- **条件不满足**：手册只给了错误命令返回 `01 00 EE 6B`。

## 九、原点回零操作说明（手册第七章）

### 9.1 单圈就近 / 方向回零（7.1）

- **两种模式的区别**：**单圈就近回零**是往靠近零点位置的方向回零；
  **单圈方向回零**是按 `O_Dir` 选项设定的方向回零。
- **前提条件**：手册未单列「前提条件」小节，操作步骤里隐含要求已经设置好单圈零点。
- **操作步骤**（手册原文三条）：
  1. 断电状态下将电机轴移动到指定位置，或上电状态下将电机轴运动到指定位置；
  2. 点击菜单 `O_Set` 中的 `Set O` 选项，**或者**发送单圈零点设置命令 `01 93 88 01 6B`，
     设置单圈回零的零点位置；
  3. 设置完成后，按需选择是否使能上电自动触发回零（`O_POT_En` 设为 `Enable`），
     也可以通讯发送「触发回零」命令（`0x9A`）进行回零。
- **面板提示**：设置成功屏幕提示 `Origin Set Done!`，失败提示 `Origin Set Fail!`
  （手册 9.1，失败提示要求「检查是否校准编码器」）。

### 9.2 多圈无限位碰撞回零（7.2）

- **原理**：利用电机运动过程中碰撞到机器结构边缘时**电流瞬间变大、转速瞬间变小**的特点
  （类似堵转检测），「让电机碰一下进行回零」。
- **前提条件**：**电机带的负载固定**。
- **检测判定条件**：`电机转速 < 碰撞回零检测转速` **+** `电机相电流 > 碰撞回零检测电流` **+**
  `持续时间 > 碰撞回零检测时间`（三个条件同时成立；阈值可在上位机或屏幕修改）。
- **操作步骤**（手册原文六条）：
  1. 先用上位机以「直通位置限速模式」控制电机带着固定负载、以「回零速度」正常运动，
     观察小屏幕此时的相电流大概是多少，比如大约 637 mA；
  2. 修改「无限位碰撞回零检测电流」比 637 mA 略大一些，比如设置为 800 mA；
  3. 修改「无限位碰撞回零检测转速」，可以设置为 300 RPM；
  4. 修改「无限位碰撞回零检测时间」，可以设置为 60 ms；
  5. 按需使能「上电自动触发回零功能」（`O_POT_En = Enable`）；
  6. 如果上电自动触发无限位回零的方向不对，可在菜单 `O_Dir` 修改回零方向。
- **对应的三个菜单项**：`O_SL_Rpm` / `O_SL_Ma` / `O_SL_Ms`（见第十三节菜单表）。

### 9.3 多圈有限位开关回零（7.3）

- **接线**：手册原文「多圈有限位开关回零根据自身使用的控制模式按照下图进行接线和设置」，
  并给出两张图：
  - **脉冲模式控制** — 上电自动回零限位开关接线；
  - **串口/232/485/CAN 通讯控制** — 上电自动回零限位开关接线。
- **前提条件 / 检测判定条件 / 操作步骤**：手册这一节**只有接线图与菜单设置说明，没有给出文字步骤**，
  即：检测判定条件与操作步骤**手册未说明**。需要额外接线这一点是手册明确要求的（按控制模式接限位开关）。
- **相关菜单**：`O_Mode = EndStop`（多圈有限位开关回零）、`O_Dir`（回零方向）、`O_POT_En`（上电自动触发回零）。
- 复用方式：`P_Serial = ESI_ALO` 时 `R/A/H` 复用为限位开关输入（手册 4.2）。

### 9.4 三种回零的前置条件对照

| 模式 | `0x9A` 模式字节 | 前提条件 | 检测判定条件 | 是否需额外接线 |
|---|---|---|---|---|
| 单圈就近 | `00` | 已设单圈零点（`O_Set → Set O` 或 `93 88`） | 手册未单列（按零点位置就近转） | 否 |
| 单圈方向 | `01` | 同上 + `O_Dir` 方向 | 手册未单列（按 `O_Dir` 方向转） | 否 |
| 多圈无限位碰撞 | `02` | **负载固定** | 转速 < 阈值 **且** 相电流 > 阈值 **且** 持续 > 阈值 | 否（靠碰撞） |
| 多圈有限位开关 | `03` | 按控制模式接线限位开关 | 手册未说明 | **是** |

## 十、到位输出与报警输出（手册第八章）

### 10.1 通讯控制模式到位输出 / 到位返回命令（8.1）

**（1）到位输出（引脚电平）**

- 菜单 `P_Pul` 选择为 `ESI_RCO` 时，当电机到位——即
  「输入位置角度 − 电机实时位置角度 < 位置到达窗口（手册此处写默认 **0.3°**，可在上位机修改）」——
  **`Dir` 引脚会输出高电平**。
- 电平由 `Com` 决定：`Com` 不接或接 3.3V → 输出 3.3V；`Com` 接 5V → 输出 5V；`Com` 接 24V → 输出 24V。
- **到位输出仅适用于非工业套餐**（不带光耦隔离的套餐）。
- 手册未说明该电平保持多久、何时拉低。

**（2）到位返回命令 `地址 + FD + 9F + 6B`**

- 该命令由驱动器在**位置模式下到位时**发出，返回帧固定 4 字节：`地址 FD 9F 6B`。
- 是否返回由菜单 `Response` 决定（语义见 2.3）：
  - `None`：不回确认、也不回到位；
  - `Receive`（默认）：只回确认收到命令；
  - `Reached`：只在发送位置模式命令时返回到位命令；
  - `Both`：确认与到位都回；
  - `Other`：位置模式下只回到位，其他控制动作命令回确认。
- 到位判据同 `0x42` 解析：目标位置与传感器实际位置相差小于**位置到达窗口**（`0x42` 示例里该字段是 `0x0001` = 1 = **0.1°**），
  此时置位「位置到达标志位」（即 `0x3A` 的 bit1）。

### 10.2 脉冲控制模式报警输出和复位堵转保护（8.2）

- 菜单 `P_Serial` 选择为 `ESI_ALO` 时，闭环电机发生**堵转、欠压等异常情况**时，
  **`T/B/L` 引脚输出 3.3V 高电平**，正常情况默认 0V 低电平。
- 发生堵转后，**将 `R/A/H` 引脚接 Gnd（0V）可以复位堵转保护，不需要重新上电**。
- 软件侧的等价操作：发 `0x0E 0x52`（解除堵转保护，见 5.3）。
- 相关菜单 `Clog_Pro` 说明里把该选项写作 `ESI_ALM`（与 `P_Serial` 菜单里的 `ESI_ALO` 名称不一致，见第十六节第 11 条）。

### 10.3 堵转检测的判定条件（4.2 `Clog_Pro` 说明）

`电机实际转速 < 设置的堵转检测转速阈值` **+** `电机实际相电流 > 设置的堵转检测相电流阈值` **+**
`持续时间 > 设置的堵转检测时间阈值`（三条同时满足）。

- 电机发生堵转时，**不管 `Clog_Pro` 是否使能，LED 都会点亮提示**；
- 使能后堵转时电机将自动关闭驱动器，保护电机与驱动器。

## 十一、`0x42 0x6C` 驱动配置参数帧：字段顺序与解析

帧结构：

| 部分 | 字节 | 说明 |
|---|---|---|
| 地址 + 功能码 | `01 42` | 2B |
| 帧长 | `21` | 「返回命令所包含的字节数 = 0x21 = 33 个」 |
| 参数个数 | `15` | 「返回命令的配置参数个数 = 0x15 = 21 个」 |
| 配置参数区 | 28B | 下表 21 个字段 |
| 校验字节 | `6B` | 1B |

> 手册的「命令返回」格式行只写了「地址 + 0x42 + 驱动配置参数 + 校验字节」，
> **没有把帧长与参数个数列成字段**；但它们确实在示例帧里，且与紧随其后的两条「= 33 个 / = 21 个」说明对应（第十六节第 12 条）。
> `0x48 0xD1` 写配置时**不带**这两个字节（写帧 33 字节 = 3 + 存储标志 1 + 参数 28 + 校验 1）。

## 十二、`0x43 0x7A` 系统状态参数帧

手册给出的完整返回示例（31 字节）：

```
01 43 1F 09 5C 67 00 03 43 EB 01 00 01 00 00 00 00 00 01 00 01 00 00 01 00 00 00 08 03 03 6B
```

| 部分 | 字节 | 说明 |
|---|---|---|
| 地址 + 功能码 | `01 43` | 2B |
| 帧长 | `1F` | 「返回命令所包含的字节数 = 0x1F = 31 个」 |
| 参数个数 | `09` | 「返回命令的配置参数个数 = 0x09 = 9 个」 |
| 系统状态参数 | 26B | 下表 9 个字段 |
| 校验字节 | `6B` | 1B |

| 序号 | 偏移 | 长度 | 字段 | 示例值 | 解析 |
|---|---|---|---|---|---|
| 1 | 1 | 2B | 总线电压 | `0x5C67` | 23655 mV |
| 2 | 3 | 2B | 总线相电流 | `0x0003` | 3 mA |
| 3 | 5 | 2B | 校准后编码器值 | `0x43EB` | 17387 |
| 4 | 7 | 5B | 电机目标位置 | 符号 `01` + `00 01 00 00` | −0x00010000 = −(65536×360)/65536 = **−360°** |
| 5 | 12 | 3B | 电机实时转速 | 符号 `00` + `00 00` | 0 RPM |
| 6 | 15 | 5B | 电机实时位置 | 符号 `01` + `00 01 00 00` | **−360°** |
| 7 | 20 | 5B | 电机位置误差 | 符号 `01` + `00 00 00 08` | −(8×360)/65536 ≈ **−0.044°** |
| 8 | 25 | 1B | 就绪状态标志 | `0x03` | 位定义同 `0x3B` |
| 9 | 26 | 1B | 电机状态标志 | `0x03` | 位定义同 `0x3A` |

> 就绪状态标志位定义（手册原文）：bit0 编码器就绪 / bit1 校准表就绪 / bit2 正在回零 / bit3 回零失败；
> 电机状态标志位定义：bit0 使能 / bit1 到位 / bit2 堵转 / bit3 堵转保护。
> 位置误差那一条，手册的计算式里把值写成了 `0x00000001` 而算式用的是 8（第十六节第 3 条）。

## 十四、常见问题与注意事项（手册第九章 + 3.2）

### 14.1 屏幕提示与处理（9.1）

| 提示 | 解决方法 |
|---|---|
| `Waiting V+ Power!` | 供电电压不足，V+ 和 Gnd 需要 12–32V 供电 |
| `Not Cal` | 未校准编码器，点 `Cal` 进行编码器校准 |
| `Phase AABB Error!` | 电机线序 A+ A− 和 B+ B− 错误，检查电机线序 |
| `Magnet Loss! Enter..` | 检测不到磁铁，未安装磁铁或未装到电机上 |
| `Encoder Error! Enter..` | 磁编码器通讯失败，可能编码器芯片已损坏 |
| `Ref Voltage Error!` | 基准电压错误，可能基准电压芯片已损坏 |
| `Bus Current Error!` | 上电瞬间总线电流过大，检查是否短路 |
| `Origin Set Done!` | 单圈回零的零点位置设置成功 |
| `Origin Set Fail!` | 零点位置设置失败，检查是否校准编码器 |
| `Going to Origin..` | 正在执行回零操作 |
| `Go to Origin Fail!` | 上电自动回零失败，检查电机力矩是否足够 |
| `Restore Done! Reboot!` | 恢复出厂设置成功，请重新上电校准编码器 |

### 14.2 上电自检提示（3.2）

| 提示 | 错误类型 | 原因与操作 |
|---|---|---|
| 提示 1 秒 `Not Cal`，然后进入校准菜单（只有 6 个菜单项） | 正常现象 | 未进行编码器校准；参考手册 3.4 上电校准编码器 |
| `Phase A+ A- Error！` / `Phase B+ B- Error！` / `Phase AA BB Error！` | 电机线序错误 | 42 步进一般黑色与绿色一组、红色与蓝色一组；也可用万用表蜂鸣档判断 |
| `Waiting V+ Power` | 电源电压太低 | 提供 12–32V，推荐 24V |
| `Magnet Loss! Enter..` | 编码器没检测到磁铁 | 按手册 2.2 安装磁铁并固定驱动板 |
| `Ref Voltage Error!` / `Bus Current Error!` | 基准电压芯片 / 电流传感器芯片故障 | 联系客服 |

### 14.3 注意事项（9.2）

1. 请勿带电拔插供电接口线和电机线，以免造成电气损坏；
2. 建议搭配本店 42 磁柱步进电机；
3. 到店一起购买 42 步进电机，会安装并校准好整套发货。

### 14.4 与写代码直接相关的几条

- 复位堵转保护有两条路：发 `01 0E 52 6B`，或把 `R/A/H` 接 Gnd（手册 8.2）。
- 使能、位置模式、速度模式的「条件不满足」大多因为**堵转保护已触发**或**电机没使能**（手册 6.3.1）。
- 位置模式命令后的「到位」不是自动回报的：默认 `Response=Receive` 只回确认帧，
  要不就得把 `Response` 改成 `Reached`/`Both`/`Other` 用 `地址 FD 9F 6B`，
  要不就轮询 `0x3A` 的 bit1（到位位）。
- 速度、位置、加速度都不影响返回帧长度；位置模式的**脉冲数与方向分离**（方向字节 + 4 字节脉冲数），
  绝对位置模式下 0 脉冲是合法值（回到原点），相对模式下 0 脉冲无意义（手册未明说，属实现选择）。
- 校准时（`0x06 45` / `Cal`）要求**开环模式且未触发堵转保护**，否则返回 `E2`。

| 修改参数 | 输入速度缩小 10 倍 | `4F 71` |
| 通讯 | XOR / CRC-8 / Modbus 校验 | —（代码硬编码 `0x6B`） |
| 通讯 | CAN 通讯（手册 6.4 整章） | — |
| 通讯 | 到位返回命令的解析 | `FD 9F`（代码只认 `[地址][功能码][02/E2][6B]`） |

### 15.3 需要留意的实现与手册的差异

1. **`Response` 与读命令**：代码假设读命令不受 `Response` 影响（模块 docstring 明写），
   手册只把 `Response` 限定在控制动作命令列表，**没有**说明读命令是否受影响——需上机确认。
2. **`Response=Reached/Both/Other` 下的到位帧**：`_write()` 读完 4 字节 ACK 后不再读后续字节。
   若面板设成会发 `地址 FD 9F 6B` 的模式，这一帧可能留在串口缓冲里被**下一条命令**读到，
   从而报 `unexpected ACK`。当前实现隐含要求「`Response` 里包含确认收到命令，且等待窗口内没有到位帧」。
3. **`0x32` 的字段宽度**：手册格式行未写宽度，代码里也没有这条命令；实现时按示例取 4 字节。
4. **回零参数块长度**：仓库根目录旧的 `电机舵机驱动命令速查.md` 把回零参数写成「12 字节、回零超时 2 字节」，
   与手册示例帧（15 字节、回零超时 4 字节）不符。本文按手册写；旧文档未在本次改动范围内。
5. **`0x43` / `0x42` 的头两个字节**：手册「命令返回」格式行没写，但示例帧与字节数说明里都有，实现时应保留。

## 十六、手册含糊 / 前后不一致 / 建议上机实测的点

以下都是校对时在手册原文里发现的矛盾或缺口，本文正文按「照抄手册 + 标注」处理，未做取舍：

1. **`0x1F` 示例帧与解析文字对不上**：示例返回 `01 1F 7D 6F 6B`（固件 0x7D、硬件 0x6F），
   解析文字却写「固件版本 = 0xF4 = Emm42_V5.0.0，硬件版本 = 0x78 = 120 = ZDT_X42_V1.2」。
   新版固件（修改记录提到 Rev1.3「增加 5.1.0 版本新固件新增功能说明」）的实际取值需实测。
2. **`0x22` 示例帧与解析表的字段值不一致**：示例帧在「无限位碰撞回零检测转速」位置是 `0F A0`（4000），
   解析表与 `0x4C AE` 写示例用的都是 `01 2C`（300 RPM）。字段位置本身没问题，取值需实测核对。
3. **`0x37` 的算式写错数**：手册写「电机位置误差 = −0x00000001 = −(8 × 360)/65536 ≈ −0.044°」，
   示例帧里是 `00 00 00 08`（即 8）。`0x43` 的解析里同样把值写成了 `0x00000001`。
4. **位置到达窗口的默认值两处不同**：8.1 写「默认 0.3°」，`0x42` 示例与解析写 `0x0001` = 1 = **0.1°**。
   另外到位判据两处都写成不带绝对值的减法（「输入位置角度 − 电机实时位置角度 < 窗口」）。
5. **一圈的量程写法 0–65535 与算式分母 65536 并存**：`0x31` 说明写「一圈的数值是 0-65535」，
   而 `0x33/0x34/0x36/0x37` 的换算式一律除以 65536。
6. **回零参数块是 15 字节**（回零超时时间占 4 字节），不是 12 字节——这一点由 `0x22`（18 字节返回）
   与 `0x4C AE`（20 字节写帧）两个示例帧的字节数唯一确定。
7. **`ID_Addr` 菜单可选地址范围两处不同**：4.2 写「1、2、…、16」，6.2.1 写「地址 1-10 可以在菜单上修改」。
8. **校验方式数量**：6.2.1 正文说三种（0x6B / XOR / CRC-8），4.2 菜单是四项（多 `Modbus`）；
   且 `0x42` 解析把「通讯校验方式」写死成 0x6B，该字段能否读回真实值未知。
9. **`UartBaud` 选项里出现 `25000`**，夹在 19200 与 38400 之间，疑为手册笔误（常见应为 28800 或 250000）。
10. **`Clog_Ma` 菜单选项写作「1800、3000、…、3000」**，首尾都是 3000，明显笔误。
11. **报警复用选项命名不一**：`P_Serial` 菜单写 `ESI_ALO`，`Clog_Pro` 菜单说明里写 `ESI_ALM`。
12. **`0x42 6C` / `0x43 7A` 的返回帧头部**：手册的「命令返回」格式行没有列出示例帧里的
    「帧长度 1B + 参数个数 1B」，只有解析文字「返回命令所包含的字节数 / 配置参数个数」与之对应。
13. **读取类命令是否受 `Response` 影响**：手册未说明（见 2.3 与 15.3）。
14. **多圈计数是否掉电保持**：`0x36` 的 4 字节字段能表达多圈位置，但手册**未说明**掉电后是否保持；
    上电后要建立绝对参考仍需回零或外部锚定。
15. **`0x9A` 的 `E2` 条件之一「单圈回零的零点位置值无效」没有给出判据**，实测前无法预判何时会触发。
16. **`0x3B` / `0x3A` 之外的忙闲信息缺失**：手册没给「正在运动」标志位，只能靠到位位与转速/位置变化判断。
17. **到位输出（8.1）的时序**：手册未说明 `Dir` 引脚到位高电平何时拉低、能否作为触发沿使用；
    且明确「仅适用于非工业套餐（不带光耦隔离）」。
18. **CAN 拆包细节**：示例里第 1 包不再带地址字节、每包重复功能码，手册未明说地址字节在 CAN 帧中的处理方式；
    CAN 应答帧 ID 规则也未说明。
