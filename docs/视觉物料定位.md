# 视觉物料定位：顶部圆面与 30 mm 测距

## 判定流程

1. `vision.hough_lock.HoughRingLocator` 对 BGR 帧做灰度化、中值滤波，再用霍夫圆变换找物料顶部圆面。默认半径范围按实际帧尺寸计算，不要求固定三个物料。
2. 找到圆面就视为有物料，输出圆心和像素半径。没有圆面时不因 YOLO 框而报告物料。
3. `vision.material_locate.MaterialLocator` 用固定的顶部**内侧浅蓝圆面直径 30 mm**计算镜头到圆面的大致距离。YOLO 只为圆面补充类别；YOLO 漏检时类别为未知，位置和距离仍保留。

`vision.material_presence` 与 `vision.material_distance` 是基于 YOLO 框的独立辅助模块，不参与这个主流程。

## 距离与标定

`distance_mm = focal_px × 30 / (2 × radius_px)`。

`models/top_pic_2.jpg` 是 1280×720 原图，内侧圆面直径约 209 px。拍摄时从镜头到圆面约 145 mm，且没有数码变焦，可反推该画幅的像素焦距约 `145 × 209 / 30 = 1012 px`。实测距离是约数，因此这是一次粗标定。

默认焦距只接受未裁切的 16:9 画幅，并按实际帧宽度从 1280 px 等比例换算。其他画幅须显式传入该画幅标定后的 `focal_px`；裁切或变焦不同也应重新标定。距离指镜头到物料顶部平面，不是机械臂末端距离。相机畸变和物料倾斜也会带来误差。

## 使用与验收

在项目根目录运行以下 PowerShell 命令；预期检出原图中一个圆面，圆心约 `(602,419)`、半径约 `105 px`，并保存标注图：

```powershell
python -m vision.material_locate --image models/top_pic_2.jpg --save output/top_pic_2_circle_result.jpg
```

仅检查霍夫定位时，预期同样检出一个圆面：

```powershell
python -m vision.hough_lock --image models/top_pic_2.jpg
```

真机运行 `python test.py` 并选菜单 18；程序向相机请求 1280×720，按 `p` 打印结论、按 `q` 退出。可通过 `--focal` 传入标定后的当前画幅像素焦距。

离线回归测试预期全部通过，不需要摄像头或安装依赖：

```powershell
python -m unittest tests.test_hough_lock tests.test_material_circle_pipeline tests.test_material_locate tests.test_material_camera_paths
```

当前验证样本只有一张完整顶视图和它的裁片。其他颜色、遮挡、不同距离及空场景的误检率仍需用相应实拍帧验收。
